## Dados coletados / processados

| Dado | Origem | Finalidade |
|------|--------|------------|
| Nome | Cadastro app / contato | Identificação, suporte, contrato |
| E-mail | Cadastro / auth | Conta, comunicação, recuperação de acesso |
| Celular / telefone | Cadastro / contato | Contato, suporte, WhatsApp comercial (site) |
| Confirmação de conta | Fluxo auth (e-mail / deep link) | Verificar e-mail, reset de senha; tokens transitórios |
| Valores gastos / previstos, categorias de custo de vida e dados financeiros informados pelo usuário | App Zwei Finance (envio pelo próprio usuário) | Funcionalidade do produto (orçamento, visão financeira) |

## Dados que NÃO coletamos / NÃO armazenamos

- Número de cartão de crédito/débito
- Números de conta bancária
- Senhas (autenticação via provedor; o site institucional não persiste senha)

## Bases legais sugeridas (template)

- Execução de contrato / medidas pré-contratuais
- Consentimento (quando aplicável)
- Legítimo interesse operacional (segurança, melhoria do serviço), com avaliação de impacto quando cabível

## Direitos do titular (LGPD)

Acesso, correção, anonimização, portabilidade, eliminação, informação sobre compartilhamentos, revogação de consentimento — via canal de privacidade.

## Compartilhamento

Prestadores essenciais (hospedagem, autenticação, e-mail) sob obrigação contratual. Sem venda de dados pessoais.

## Retenção

Pelo tempo necessário às finalidades, obrigações legais e defesa de direitos; depois exclusão ou anonimização.
